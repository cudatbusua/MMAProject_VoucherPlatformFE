# Voucher Mongo API

Hướng dẫn đầy đủ nằm ở [README của project](../README.md).

```powershell
npm.cmd run db:local
# Terminal khác:
npm.cmd run db:seed
npm.cmd run start:dev
```

Swagger: http://127.0.0.1:4100/docs

`db:seed` chỉ cần cho dữ liệu mẫu ban đầu. Database lưu ở `.data/mongo`; file `.env` chứa cấu hình riêng của project mới.
